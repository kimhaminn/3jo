# 03. 아키텍처 결정 기록 (ADR)

> HMC SCM (Hyundai Motor Company Supply Chain Management) 시스템

---

## ADR-001. JSP + Servlet 기반 MVC 패턴 채택

**결정**: 프론트엔드는 JSP(View), 백엔드 로직은 Servlet으로 분리하는 MVC 패턴 적용  
**이유**: 팀 전체가 Java 기반 웹 개발에 익숙하며, 별도 프레임워크 학습 비용 최소화  
**결과**: 공통 UI 컴포넌트(navbar, sidebar, footer)를 JSP include 방식으로 재사용

---

## ADR-002. MySQL 단일 데이터베이스 사용

**결정**: `hmc_scm` 스키마 하나에 모든 테이블 관리  
**이유**: 소규모 시스템이므로 단일 DB로 운영하는 것이 관리 효율이 높음  
**결과**: JDBC `DBUtil.getConnection()`으로 일원화된 연결 관리

---

## ADR-003. Naver Maps API 지도 연동

**결정**: 납품 경로 시각화에 Naver Maps & Directions API 채택  
**이유**: 국내 주소 데이터 정확도 및 한국어 지원 측면에서 우수  
**결과**: JSP Proxy 방식으로 API Key를 서버에서 관리하여 보안 강화

---

## ADR-004. 유전 알고리즘 기반 공급 최적화

**결정**: 복수 벤더 간 공급 배분 최적화에 유전 알고리즘 적용  
**이유**: 벤더 수와 부품 종류가 많을 경우 조합 최적화 문제를 효율적으로 해결 가능  
**결과**: `supplymgt.jsp`에서 실시간 최적 배분 결과 제공
