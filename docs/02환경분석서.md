# 02. 환경 분석서

> HMC SCM (Hyundai Motor Company Supply Chain Management) 시스템

---

## 1. 외부 시스템 연동

| 외부 시스템 | 연동 방식 | 목적 |
|-------------|-----------|------|
| **Naver Maps API** (지도 서비스) | REST API (HTTP GET) | 납품 경로 최적화, 실시간 배송 위치 지도 표시 (`delivery.jsp`, `bestroute2.jsp`) |
| **Naver Directions API** | REST API (Proxy via JSP) | 출발지 → 목적지 경로 안내 및 예상 소요시간 계산 |
| **Google Fonts** | CDN | UI 폰트(Noto Sans KR, Share Tech Mono) 제공 |
| **Font Awesome** | CDN | 아이콘 라이브러리 |

---

## 2. 외부 프로세스

- 벤더사의 사업자등록증, 법인등록증, 기술인증 서류를 시스템 외부(오프라인)에서 수집 후 시스템 내 업로드
- 정산 처리는 현재 외부 ERP/회계 시스템과 별도로 운영 (추후 연동 검토)
