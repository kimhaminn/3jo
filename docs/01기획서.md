# 01. 기획서

> HMC SCM (Hyundai Motor Company Supply Chain Management) 시스템

---

## 1. 배경

제조업 공급망 관리의 복잡성이 증가함에 따라, 원청기업(현대자동차)과 벤더사(부품 협력업체) 간의 발주, 납품, 평가, 정산 업무를 통합 관리하는 디지털 플랫폼의 필요성이 대두되었다.  
기존의 수작업 또는 분산된 시스템으로는 실시간 현황 파악, 납기 준수율 관리, 다단계 승인 처리에 한계가 있었다.

---

## 2. 목적

- 원청기업과 벤더사 간 발주·입찰·납품·평가·정산 프로세스를 단일 웹 플랫폼에서 통합 처리
- 실시간 KPI(납기 준수율, 진행 중 발주 수, 검토 대기 입찰 수 등) 모니터링을 통한 의사결정 지원
- 다단계 사용자 승인 체계(SCM 관리자 → 원청기업 관리자)를 통한 보안 강화
- 벤더사 평가 자동화 및 성과 보고서 제공으로 협력사 관리 효율화

---

## 3. 범위

| 구분 | 포함 범위 |
|------|-----------|
| 사용자 관리 | 회원가입, 로그인, 다단계 승인, 프로필 관리 |
| 발주 / 입찰 | 발주 등록, 발주 현황, 입찰 신청, 입찰 심사 |
| 납품 관리 | 납품 현황 목록, 납품 상세(지도 연동) |
| 공급 최적화 | 벤더별 공급 배분 최적화(유전 알고리즘) |
| 평가 / 보고 | 업체 평가, 벤더 성과 보고서 |
| 정산 | 정산 현황 |
| 공지 | 공지사항 등록 및 읽음 처리 |
| 부품 DB | 자동차 부품 데이터베이스 조회 |

---

## 4. 고객 및 사용자 구분

| 역할 | 구분 | 설명 |
|------|------|------|
| **SCM 관리자** (`scm`) | 내부 사용자 | 시스템 전체 관리자. 사용자 승인/거절, 발주 삭제, 공지 등록, 모든 데이터 조회 가능 |
| **원청기업 관리자** (`admin`) | 내부 사용자 | 현대자동차 소속 담당자. 발주 등록, 벤더 승인, 입찰 심사, 평가 조회 가능 |
| **벤더사** (`vendor`) | 외부 사용자 | 부품 협력업체 담당자. 입찰 신청, 납품 현황 조회, 본인 평가 조회 가능 |

> 승인 흐름: 벤더사 가입 → SCM 승인 → 원청기업 승인 → 최종 APPROVED  
> 원청기업 가입 → SCM 승인 → 최종 APPROVED
