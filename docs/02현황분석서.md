# 02. 현황 분석서

> HMC SCM (Hyundai Motor Company Supply Chain Management) 시스템

---

## 1. 기존 시스템 현황

- 통합 SCM 웹 시스템 부재; 발주/납품 관련 업무를 이메일·엑셀로 처리
- 사용자 인증 및 권한 관리 체계 미흡 (단일 계정 공유 등)
- 납기 준수율, 벤더 평가 등 KPI 지표를 수작업으로 집계

---

## 2. 기존 프로세스

| 업무 | 기존 방식 |
|------|-----------|
| 발주 | 이메일로 발주서 전송 → 벤더사 수동 확인 → 구두/메일 회신 |
| 입찰 | 견적서 개별 수신 → 담당자가 수동 비교·선정 |
| 납품 확인 | 전화 또는 이메일로 납품 상태 확인 |
| 벤더 평가 | 연 1회 수동 집계 후 보고서 작성 |

---

## 3. 문제점 요약

| 문제 영역 | 문제 내용 |
|-----------|-----------|
| 가시성 | 실시간 발주·납품 현황 파악 불가 |
| 보안 | 단일 계정 공유로 인한 접근 제어 취약 |
| 효율성 | 반복적인 수작업으로 인한 업무 지연 |
| 데이터 | KPI 지표 실시간 집계 불가 |
