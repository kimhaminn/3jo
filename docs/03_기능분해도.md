## 2. 메뉴 구조

```
HMC SCM 시스템
├── 메인
│   └── 대시보드
├── 발주 / 입찰
│   ├── 발주 등록 (Admin, Vendor)
│   └── 발주 현황
├── 관리
│   ├── 납품 현황
│   ├── 업체 평가
│   └── 정산
├── 공급 관리
│   ├── 공급 최적화
│   └── 부품 DB
├── 공지사항
└── 사용자
    ├── 프로필
    ├── 사용자 승인 (SCM, Admin)
    └── 로그아웃
```

## 3. 스토리보드 (주요 흐름)

```
[로그인] → 역할 선택 → ID/PW 입력 → 승인 상태 확인 → [대시보드]

[발주 흐름]
Admin: 발주 등록 → 발주 현황 확인
Vendor: 발주 현황 조회 → 입찰 신청 → 심사 대기
SCM: 입찰 목록 확인 → 낙찰 처리

[납품 흐름]
납품 현황 목록 → 납품 상세 → 지도로 경로 확인

[평가 흐름]
업체 평가 목록 → 평가 상세 → 연도별 이력 확인 → 보고서 출력
```
