# 03. UI 설계서

> HMC SCM (Hyundai Motor Company Supply Chain Management) 시스템

---

## 1. 디자인 스타일

- **테마**: 다크 모드 (Dark Blue 계열)
- **주요 색상**:
  - Primary: `#003DA5` (현대차 블루)
  - Accent: `#00AAD4` (시안)
  - Background: `#0D1B2A` (다크 네이비)
  - Surface: `#112240`
  - Success: `#00E5A0`
  - Warning: `#F59E0B`
  - Danger: `#EF4444`
- **폰트**: Noto Sans KR (본문), Share Tech Mono (수치/코드)
- **아이콘**: SVG 인라인 아이콘, Font Awesome

---

## 2. 레이아웃 배치

```
┌─────────────────────────────────────────┐
│              NAVBAR (상단 56px)          │
├──────────────┬──────────────────────────┤
│              │                          │
│   SIDEBAR    │       MAIN CONTENT       │
│   (220px)    │       (나머지 전체)        │
│              │                          │
├──────────────┴──────────────────────────┤
│                 FOOTER                   │
└─────────────────────────────────────────┘
```

---

## 3. 메뉴 위치

| 영역 | 포함 요소 |
|------|-----------|
| **상단 Navbar** | 로고, 알림(미읽음 뱃지), 사용자 정보, 로그아웃 |
| **좌측 Sidebar** | 전체 메뉴 네비게이션, 역할/회사명 표시, 현재 페이지 하이라이트 |
| **하단 Footer** | 저작권, 버전 정보, 이용약관/개인정보처리방침 링크 |
