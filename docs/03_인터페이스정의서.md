# 03. 인터페이스 정의서

> HMC SCM (Hyundai Motor Company Supply Chain Management) 시스템

---

## 1. 외부 API 인터페이스

| 인터페이스 | 방식 | 엔드포인트 | 사용 화면 | 목적 |
|------------|------|-----------|-----------|------|
| Naver Maps API | REST (HTTP GET) | Naver Maps REST API | `delivery.jsp`, `bestroute2.jsp` | 납품 경로 및 배송 위치 지도 표시 |
| Naver Directions API | REST (JSP Proxy) | Naver Directions REST API | `bestroute2.jsp` | 출발지 → 목적지 경로 안내 및 예상 소요시간 |

---

## 2. 사용자 승인 프로세스

```
벤더사/원청기업 회원가입 (status: PENDING)
    ↓
SCM 관리자 승인 (approved_by_scm = 1)
    ↓ (벤더사의 경우 추가 단계)
원청기업 관리자 승인 (approved_by_admin = 1)
    ↓
최종 APPROVED → 로그인 가능
```

---

## 3. 발주·입찰 프로세스

```
원청기업(Admin): 발주 등록 (status: OPEN)
    ↓
벤더사(Vendor): 발주 목록 조회 → 입찰 신청 (status: PENDING)
    ↓
SCM/Admin: 입찰 검토 → 낙찰 처리 (status: CLOSED)
```
