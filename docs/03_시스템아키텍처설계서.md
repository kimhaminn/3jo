# 03. 시스템 아키텍처 설계서

> HMC SCM (Hyundai Motor Company Supply Chain Management) 시스템

---

## 1. 기술 스택

| 계층 | 기술 |
|------|------|
| **프론트엔드** | HTML5, CSS3, JavaScript (Vanilla), JSP (View 역할) |
| **백엔드** | Java (JSP + Servlet), JDBC |
| **데이터베이스** | MySQL (`hmc_scm` 스키마) |
| **외부 API** | Naver Maps API, Naver Directions API |
| **서버** | Apache Tomcat (JSP 컨테이너) |

---

## 2. 아키텍처 흐름

```
[브라우저]
    ↕ HTTP Request/Response
[Apache Tomcat]
    ↕ JDBC (DBUtil.getConnection())
[MySQL - hmc_scm DB]

[브라우저] ←→ [JSP (Naver API Proxy)] ←→ [Naver Maps/Directions API]
```
