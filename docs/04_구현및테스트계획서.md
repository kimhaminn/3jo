## 2. 테스트 계획

| 테스트 항목 | 시나리오 | 예상 결과 |
|-------------|----------|-----------|
| 로그인 | 미승인 계정 로그인 시도 | 승인 대기 안내 메시지 출력 |
| 로그인 | 잘못된 ID/PW 입력 | 오류 메시지 출력 |
| 발주 등록 | 필수 항목 누락 후 제출 | 유효성 검사 오류 출력 |
| 입찰 신청 | 벤더사 계정으로 입찰 신청 | 입찰 목록에 PENDING 상태로 등록 |
| 권한 제어 | 벤더사로 발주 등록 페이지 접근 | `bidList.jsp`로 리다이렉트 |
| Naver API | 납품 상세 페이지 지도 로드 | 경로 지도 정상 출력 |
| 공지 읽음 | 공지 클릭 후 읽음 처리 | 알림 뱃지 수 감소 |
