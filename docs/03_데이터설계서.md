# 03. 데이터 설계서

> HMC SCM (Hyundai Motor Company Supply Chain Management) 시스템

---

## 1. 주요 DB 테이블

| 테이블명 | 설명 |
|----------|------|
| `users` | 사용자 계정 (역할, 승인 상태 포함) |
| `vendors` | 벤더사 기업 정보 |
| `bids` | 발주 정보 |
| `bid_applications` | 벤더 입찰 신청 내역 |
| `deliveries` | 납품 현황 |
| `evaluations` | 벤더사 평가 이력 |
| `notices` | 공지사항 |
| `notice_reads` | 공지 읽음 처리 |
| `parts` | 부품 정보 |
| `parts_db` | 자동차 부품 카탈로그 DB |

---

## 2. 데이터베이스 정보

- **DBMS**: MySQL
- **스키마명**: `hmc_scm`
- **연결 방식**: JDBC (`DBUtil.getConnection()`)
