# 데이터 설계서 (Data Design)

## 1. 개요

본 문서는 '3jo-tajo' 프로젝트의 데이터베이스 설계에 대한 개요를 제공한다. 제공된 소스 코드(`DBUtil.java`)를 기반으로 데이터베이스 연결 정보 및 사용되는 데이터베이스 시스템을 식별한다.

## 2. 데이터베이스 시스템 정보

*   **데이터베이스 종류:** MySQL
*   **데이터베이스명:** `HMC_SCM`
*   **접속 정보:**
    *   **URL:** `jdbc:mysql://localhost:3306/HMC_SCM?useSSL=false&serverTimezone=Asia/Seoul&characterEncoding=UTF-8`
    *   **사용자명:** `root`
    *   **비밀번호:** `1234`

## 3. 논리/물리 DB 설계 및 데이터 스키마 명세

제공된 `WEB-INF.zip` 파일에는 데이터베이스 스키마 정의(DDL) 파일이나 엔티티 관계 다이어그램(ERD)과 같은 상세한 데이터베이스 설계 정보가 포함되어 있지 않다. 따라서 현재 단계에서는 논리/물리 DB 설계 및 데이터 스키마 명세를 구체적으로 정의하기 어렵다.

**향후 필요 사항:**

*   프로젝트의 비즈니스 요구사항을 기반으로 한 엔티티 및 속성 정의
*   테이블 구조, 컬럼 정의, 데이터 타입, 제약 조건(Primary Key, Foreign Key 등) 명세
*   관계형 데이터베이스의 경우 ERD 작성
*   데이터베이스 정규화 수준 결정

## 4. 저장소 정책 및 제약 조건

현재 제공된 정보만으로는 저장소 정책 및 제약 조건을 파악하기 어렵다. 일반적으로 다음 사항들을 고려해야 한다.

*   **데이터 백업 및 복구 정책:** 데이터 손실 방지를 위한 백업 주기 및 복구 절차.
*   **데이터 보존 정책:** 법적 또는 비즈니스 요구사항에 따른 데이터 보존 기간.
*   **성능 최적화:** 인덱스 전략, 쿼리 최적화 방안.
*   **보안:** 데이터 암호화, 접근 제어, 감사 로깅.
