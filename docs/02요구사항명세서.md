# 02. 요구사항 명세서

> HMC SCM (Hyundai Motor Company Supply Chain Management) 시스템

---

## 1. 기능 요구사항

| ID | 구분 | 요구사항 | 관련 화면 |
|----|------|----------|-----------|
| F-01 | 사용자 | 역할(SCM/원청/벤더)을 선택하여 회원가입할 수 있어야 한다 | `signup.jsp` |
| F-02 | 사용자 | 다단계 승인(SCM → 원청) 후 로그인이 가능해야 한다 | `login.jsp`, `adminApproval.jsp` |
| F-03 | 발주 | 원청기업은 부품 정보(이미지 포함)와 함께 발주를 등록할 수 있어야 한다 | `bidReg.jsp` |
| F-04 | 발주 | 벤더사는 진행 중인 발주 목록을 조회하고 입찰 신청할 수 있어야 한다 | `bidList.jsp`, `bidItemReg.jsp` |
| F-05 | 납품 | 납품 현황을 목록으로 조회하고 지도로 배송 경로를 확인할 수 있어야 한다 | `deliveryList.jsp`, `delivery.jsp` |
| F-06 | 평가 | SCM/원청은 벤더사를 점수 기반으로 평가하고 이력을 조회할 수 있어야 한다 | `evaluationList.jsp`, `evaluation.jsp` |
| F-07 | 공급 최적화 | 유전 알고리즘 기반으로 복수 벤더 간 최적 공급 배분을 산출할 수 있어야 한다 | `supplymgt.jsp` |
| F-08 | 공지 | SCM/원청은 역할별 타겟 공지를 등록하고 읽음 처리가 가능해야 한다 | `notice.jsp`, `noticeRead.jsp` |
| F-09 | 보고 | 벤더 성과 보고서를 화면에서 조회하고 이메일로 전송할 수 있어야 한다 | `vendorReport2.jsp` |
| F-10 | 부품 DB | 부품 코드·이름·차량 도메인 기준으로 부품 데이터베이스를 검색할 수 있어야 한다 | `parts_db_view.jsp` |

## 2. 품질 기준

| 품질 속성 | 기준 | 비고 |
|-----------|------|------|
| **보안성** | 모든 페이지 세션 인증 필수; 역할별 접근 제어 적용 | 미승인 사용자 로그인 차단 |
| **가용성** | 핵심 기능(발주·납품) 정상 운영 | 외부 API 장애 시 지도 기능 제외 서비스 유지 |
| **성능** | 목록 조회 응답시간 3초 이내 | 페이지네이션(20건) 적용 |
| **유지보수성** | 공통 컴포넌트(navbar, sidebar, footer) 분리 | JSP include 방식 |
| **호환성** | 최신 Chrome, Edge 브라우저 지원 | 반응형 레이아웃 적용 |
